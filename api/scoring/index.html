Scoring

The scale-free marginal score and its sort-and-sweep, on VisualGeometryCore's scoring contract, and the loss-width ("threshold-based") scorings it is compared against.

Problems and the scoring contract

A problem is scored through VisualGeometryCore's constraint-problem protocol: it subtypes AbstractConstraintProblem and implements data_size, codimension, minimal_sample_size and constraint_with_jacobians; predictive scoring additionally needs solver_covariance, declared by provides_solver_covariance. A scorer implements VisualGeometryCore's scoring contract (scoring_workspace, score!, inlier_count, consensus_order, …), and the scale prior IGPrior (Jeffreys: JeffreysPrior()), the Student-t + uniform mixture toolkit and the Gaussian-uniform boundary (GauInlier, decision_threshold) are VisualGeometryCore's too. The concrete problems (homography, fundamental and essential matrix, …) live in RobustVisualGeometry.

The scale-free marginal score

StudentTUniformScoring carries the configuration (outlier half-width, model degrees of freedom, scale prior, the profile-prior flag); ScoringWorkspace carries the scratch buffers of the sort-and-sweep — the scoring contract's scoring_workspace. StudentTUniformScoring{Predictive} scores a model with its solver covariance.

RansacScoringDoneRight.StudentTUniformScoring — Type
StudentTUniformScoring{P, DG} <: GauScoring

The scale-free marginal score of the Student-t inlier + uniform outlier model (Section 3, Eq. 12) — spec only: the immutable configuration of the score (outlier half-width, model DOF, scale prior, profile-prior flag). Its scratch (perm, lgtable, penalties, sortkey, priortable) lives on its ScoringWorkspace, the scoring contract's `scoringworkspace`.

Parameterized by:

  • P: Nothing (model-certain) or Predictive (model-uncertain)
  • DG::Int: Codimension dg of the model manifold (compile-time constant)

The score marginalizes σ² under the scale prior (Jeffreys π(σ²) ∝ 1/σ² by default):

S(θ, I) = log Γ((nᵢ·dg − n_θ)/2) − ((nᵢ·dg − n_θ)/2) log(π·RSS_I) − nₒ·dg·log(2h)

where nᵢ = |I|, RSSI = Σᵢ∈I rᵢ², nₒ = N − nᵢ, nθ = m·dg (model parameters), h is the outlier half-width, and dg the codimension.

Per-point scores ‖rᵢ‖² = gᵢᵀ Σ̃{gᵢ}⁻¹ gᵢ, where rᵢ = Lᵢ⁻¹gᵢ is the shape-whitened residual. For the predictive variant, Σ̃{gᵢ} includes model estimation uncertainty.

Build it with StudentTUniformScoring(problem | P | model_dof, outlier_halfwidth; prior = JeffreysPrior(), profile_prior = false) (the model_dof form takes codimension), or StudentTUniformScoring{Predictive}(problem | P, outlier_halfwidth; …).

Fields

  • outlier_halfwidth::Float64: the half-width of the uniform outlier support (the sweep charges log(2·outlier_halfwidth) per point and axis)
  • model_dof::Int: Minimal sample size m = ⌈n_θ/dg⌉
  • profile_prior::Bool: Whether the profiled-γ correction is used (the workspace's prior_table): the profiled label prior γ̂ = nᵢ/N instead of the flat γ = ½.
  • scale_prior::IGPrior: Scale prior for σ² marginalization. Jeffreys is IGPrior(0.0, 0.0); weakly-informative IG is IGPrior(α₀, β₀).

Predictive

Type tag for the predictive variant of StudentTUniformScoring.

StudentTUniformScoring{Predictive} incorporates model estimation uncertainty (Σ̃θ from `solvercovariance, of a minimal-sample model or of a refit on its consensus set) into per-point scores.StudentTUniformScoring{Nothing}` treats the model as exact (Σ_θ = 0).

See also: StudentTUniformScoring, StudentTUniformScoring{Predictive}

RansacScoringDoneRight.ScoringWorkspace — Type
ScoringWorkspace

Pre-allocated scratch buffers for scale-free marginal scoring (Algorithm 1).

Separated from StudentTUniformScoring so that scoring carries only the immutable spec (model DOF, outlier half-width, codimension) while the mutable workspace lives on RansacWorkspace. Mirrors the spec/workspace split already in place for local-optimization via lo_ws.

Prior consistency

The lg_table is built at allocation time with a specific α₀ — once a ScoringWorkspace is constructed it is committed to that scale prior. The scale_prior field is the single source of truth for which prior the buffers are configured for; sweep!(sws, ...) reads it from here rather than accepting a runtime kwarg, which would risk pairing a Jeffreys lg_table with an IG score formula.

Fields

  • perm::Vector{Int} — sortperm buffer, mutated by every sweep!
  • scratch::Vector{Int} — sortperm scratch (comparison-sort fallback paths)
  • radix::RadixPermBuffers — scratch for the allocation-free stable radix sortperm taken by the exact-size single-sort fast path (bitwise-identical permutation; see _radix_sortperm!)
  • lg_table::Vector{Float64} — log Γ(k·dg/2 + α₀); depends on n, dg, and the scale prior
  • penalties::Vector{Float64} — per-point ℓᵢ = log|Ṽᵢ| (predictive scoring)
  • sort_key::Vector{Float64} — the sweep ordering key: the per-point unit-scale Mahalanobis q in Predictive scoring (raw r² only in the model-certain fallback). The historical raw-r² key is retired — with heterogeneous penalties sweep! follows the generalized sweep lemma's parametric ordering.
  • prior_table::Vector{Float64} — profiled-γ correction; empty = flat prior
  • scale_prior::IGPrior — the prior the lg_table was built for (α₀=β₀=0 ⇒ Jeffreys)

Build with alloc_scoring_workspace(problem, scoring) (defined in estimators/ransac/scoring.jl) or default_scoring_workspace(n; dg, scale_prior).

RansacScoringDoneRight.score_residuals! — Function
score_residuals!(sws, q, scoring, residuals, n; sample_idx = nothing) -> (S, k)

Score from precomputed residuals (model-certain, isotropic noise).

Squares residuals[1:n] into q, pads q[n+1:end] with typemax, zeros the sws penalties, and sweeps for the optimal partition (overwriting the sws sweep buffers). The sample_idx points get q = 0.

Returns (S, k): sweep score and optimal inlier count.

score_sq_residuals!(sws, q, scoring::StudentTUniformScoring{Predictive}, problem, model, sample_idx, n) -> (S, k)

Predictive variant: compute model-uncertain scores qᵢ from solver Jacobian, then sort-and-sweep (Algorithm 1, Eq. 20).

Computes Σ̃θ from `solvercovariance(problem, model, sampleidx), then fillsq[i]with the predictive squared residual rᵢᵀ Ṽᵢ⁻¹ rᵢ. A problem with nosolvercovariance` throws (see its docstring).

Returns (S, k): sweep score and optimal inlier count. A DEGENERATE sample — the provider returns nothing — is no hypothesis: (-Inf, 0), as for a failed solve, with q and sws untouched. It is never scored model-certain. Otherwise it is the covariance-given method below at that Σ̃_θ.

score_sq_residuals!(sws, q, scoring::StudentTUniformScoring{Predictive}, problem, model, Σ̃_θ,
                    sample_idx, n; residuals = nothing) -> (S, k)

Predictive scoring at a GIVEN unit-scale model covariance Σ̃_θ. The convention is multiplicative, Σ_θ = s²·Σ̃_θ, and Σ̃_θ is a minimal sample's solver_covariance, or a refit's on its consensus set, as an Uncertain model carries it. Fills q[i] with the predictive squared residual rᵢᵀ Ṽᵢ⁻¹ rᵢ and the sws penalties with log|Ṽᵢ|, then sort-and-sweeps (Algorithm 1, Eq. 20).

sample_idx (or nothing): the minimal sample's points, which satisfy their constraints exactly — their q and penalty are set to zero, as q is in score_residuals!. When residuals is supplied it receives each point's whitened_residual from the same constraint evaluation — SIGNED for a scalar constraint, exactly what residuals! writes.

Returns (S, k): sweep score and optimal inlier count.

Loss-width scorings

The baselines of the paper (RANSAC, MSAC, GaU/MLESAC, MAGSAC++) and three robust costs, each a singleton type carrying its codimension and scored through one per-residual scalar, VisualGeometryCore's residual_quality. RANSAC and MSAC are VisualGeometryCore's baseline scorers (RansacScoring, MsacScoring); this package adds their grid methods.

RansacScoringDoneRight.LossWidthScoring — Type
LossWidthScoring{DG}

The loss-width-parameterised scorings of both branches at codimension DG — the paper's "threshold-based family". A Union, not a supertype: "takes a loss width" cuts across GauScoring and LossCostScoring, so it cannot be a supertype of both without implying a mixture underneath the losses, which is exactly what the retired ThresholdFamily got wrong.

This is the type the loss-width sweep entry points accept. Widening them to AbstractScoring would readmit StudentTUniformScoring, which has no loss width and would fail several frames down inside GPU staging instead of at the call site.

RansacScoringDoneRight.loss_width_scoring — Function
loss_width_scoring(method::Symbol[, dg | problem]) -> LossWidthScoring

The LossWidthScoring member a Symbol names — :ransac, :msac, :mlesac, :magsac, :welsch_cost, :smooth_tls, :geman (the tag rule: the type's name without Scoring, snake_cased) — at codimension dg, or at codimension(problem). Bare, it is codimension 1.

Supply the codimension whenever the problem has one other than 1: the Symbol vocabulary must not be a back door that silently re-defaults DG.

It returns a member of the LossWidthScoring union, and is named for it.
