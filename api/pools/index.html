Pools, grids and tuning

Scoring over a benchmark pool: VisualGeometryCore's light PoolPair record together with its num_points × num_models Float32 residual matrix, both in the pool frame NormalizedImageFrame (see Conventions). No function here opens a file; pool IO belongs to VisualGeometryEval.

Per-pair model selection

VisualGeometryCore.best_pool_model — Function
best_pool_model(scoring::LossWidthScoring, pair::PoolPair, R, loss_width::Real) -> Int

Index of the best-scoring stored pool model of pair under the width-free loss-width family scoring at loss_width, scored on its residual matrix R (num_points(pair) × num_models(pair), Float32, NormalizedImageFrame units — loss_width is in that unit too): per model Σᵢ residual_quality(scoring, dᵢ², loss_width) (pool_model_score), exactly the Exact grid's (grid_evaluate) per-model score on this one pair. 0 means no model (see the sentinel contract above); a matrix of another shape is a DimensionMismatch. A scorer AT its width (MsacScoring(dg; threshold = w), a StudentTUniformScoring) goes through VisualGeometryCore's 3-argument best_pool_model(scoring, pair, R) — the same arithmetic, through score!.

RansacScoringDoneRight.pool_model_score — Function
pool_model_score(scoring::LossWidthScoring, pair::PoolPair, R, j, loss_width[, q0]) -> Float64

Score of the stored pool model j of pair under a loss-width family (MsacScoring, RansacScoring, MagsacScoring, the loss scorings) at loss_width. It is Σᵢ residual_quality(scoring, dᵢ², loss_width) over the model's column of the pair's residual matrix R (num_points(pair) × num_models(pair), Float32, in NormalizedImageFrame units — the pool frame's, as is loss_width). The ONE per-model loss-width score: best_pool_model is its argmax, the Exact grid (grid_evaluate with Exact()) computes the same value, and a running-best selector over a pool calls it per (pair, j) rather than re-summing the quality.

The stack's minimal-sample rule, the same in every scorer: the model's minimal-sample points (pair.sample_indices[:, j]) are fit exactly by construction and carry no information, so they enter at ZERO residual whatever was stored for them — here each contributes the constant q0 = residual_quality(scoring, 0, loss_width), identical for every model of the pool, so the ranking is that of the non-sample points alone. (The marginal scorers zero the same entries and subtract the model's m dof in the partition evidence, ν = dg·(k − m).) A non-finite stored d is an outlier (quality 0); finiteness is tested before squaring, so a finite d whose square overflows also scores 0. An invalid sample index throws. q0 is an optional precomputed cache.

RansacScoringDoneRight.precompute_pair — Function
precompute_pair(pair::PoolPair, R) -> PrecomputedPair

Per-pair staging precompute of pair and its residual matrix R (num_points × num_models, Float32, NormalizedImageFrame units). Each model column is squared in Float32, its minimal-sample points zeroed (exact inliers; an out-of-range index THROWS, as in every other scorer) and sorted; the selection error pool_imc is kept per model.

Grid selection: the pool-selection contract

VisualGeometryCore's select_on_grid!(idxs, P, scoring, grid, staged) fills idxs[p, t] with the model selected for pair p at width grid[t]. Every grid family of this package (StudentTUniformScoring, the width-free loss-width families, LossSpec, ScaleMarginal, SimFitPP) declares the staging :rsdr: stage_selection(selection_staging(scoring), pairs, residuals; backend) is one stage_ig_shared_from_pairs shared by all of them, and its select_on_grid! is one grid_evaluate (SIMFIT++: its host loop over simfitpp_select). pair_chunk_budget sizes the device chunks.

RansacScoringDoneRight.pair_chunk_budget — Function
pair_chunk_budget(M_max, T) -> Int

Pairs per chunk of a device selection grid over T columns of pools with up to M_max models: the chunk bounds the score block (Float64, pairs × M_max × T) plus argmax's broadcast temporary under ~6 GiB, clamped to [1, 256]. T-aware, so a wide miscalibration grid (T up to ~600) stays in device memory and narrow validation grids keep the chunk large.

Grid evaluation (CPU and GPU)

A pool is staged once (stage_ig_shared_from_pairs) and every scorer is evaluated over a grid of its native width by one verb, grid_evaluate, which dispatches on the scoring. The kernels are written with KernelAbstractions and run on CPU() or a CUDA backend.

RansacScoringDoneRight.IGSharedData — Type
IGSharedData{Backend, F32A, F64A, IntA}

Backend-agnostic flat-layout view of every PrecomputedPair in a pool. Built once per pool by stage_ig_shared_from_pairs and reused by every grid evaluator.

Memory layout — all distinct pairs flattened:

  • sorted_sq_flat::F32A (a vector of the pool's residual eltype on backend) contiguous concatenation of all (Ki × Mi) sortedsq matrices in column-major order: pair 1 model 1 (length K1), pair 1 model 2, …, pair 1 model M_1, pair 2 model 1, …
  • pair_offset::IntA (length P+1) pair_offset[p] = absolute starting index of pair p in sorted_sq_flat. pair_offset[P+1] = total length (sentinel).
  • K_per_pair::IntA (length P) — # residuals for each pair
  • M_per_pair::IntA (length P) — # models for each pair
  • M_max::Int — max # of models across all pairs (kernel grid sizing)
  • errors_imc_flat::F64A — concatenated per-model selection imc = pool_imc (H: Δrot; E/F: max(Δrot,Δtrans)), indexed by errors_offset[p] + j
  • errors_offset::IntA — errors_offset[p] = start of pair p's imc segment

P is the number of pairs in the pool.

stage_ig_shared_from_pairs(pairs, residuals; backend) -> IGSharedData

Stage a pool once for every grid evaluator. The inputs are the light records pairs (AbstractVector{<:PoolPair}) with their residual matrices residuals (residuals[p] is pair p's num_points × num_models Float32 matrix, in NormalizedImageFrame units — the caller loads them; staging opens no file), each pair precomputed by precompute_pair into the flat IGSharedData layout on backend. RansacScoringDoneRight.grid_evaluate — Function
grid_evaluate(scoring::StudentTUniformScoring, staged::IGSharedData, outlier_halfwidths;
              pair_chunk_size = 256, return_idxs = false) -> Matrix{Float64}

The Student-t marginal grid (the IG/Jeffreys sort-and-sweep) on the staged pool's backend. It returns a (P, T) matrix of each pair's error at the model scoring selects at each outlier half-width in outlier_halfwidths (NormalizedImageFrame units). The grid REPLACES the scoring's own outlier half-width; its minimal sample size, codimension and scale prior are the scoring's. With return_idxs, also the (P, T) Int32 selected model indices.

Runs ig_sweep_kernel! on the shared chunked driver (_chunked_argmax_eval): pair-chunks of pair_chunk_size bound the score block, and the model argmax is the shared argmax_models_kernel!, which takes the FIRST strictly best model and SKIPS a NaN score. The device sweep scores the model-certain marginal with the flat label prior only: a StudentTUniformScoring{Predictive} or a scoring with profile_prior = true is an ArgumentError, never scored as something else.

source
grid_evaluate([S = Float32,] scoring::LossWidthScoring, staged::IGSharedData, loss_widths;
              aggregation = LogBinned(), return_idxs = false, pair_chunk_size = 256)
    -> Matrix{Float64}

Per-pair selection errors of a loss-width family over a loss-width grid. They form a (P, T) matrix of the error (imc) of the model scoring selects at each loss width in loss_widths (NormalizedImageFrame units; with return_idxs, also the selected pool indices). Runs on the staged data's backend — KernelAbstractions CPU() or a GPU.

aggregation chooses the algorithm: LogBinned (default, 200 bins per decade; the fast cross-validation path) or Exact (every residual; the reference). Both evaluate the family's one per-residual quality. S is the LogBinned kernel's bin-index precision (Float32, the default, is the production setting); Exact evaluates in Float64. Scores accumulate in Float64 either way.

scoring is a LossWidthScoring member — build it with loss_width_scoring, supplying the problem's codimension.

source
grid_evaluate([S = Float32,] m::ScaleMarginal, staged::IGSharedData, prior_loss_widths;
              NG = _MARG_NG, return_idxs = false, mem_budget = 6_000_000_000)
    -> Matrix{Float64}

Full-data scale-marginal scoring (WelschMarginal, SmoothTLSMarginal) at precision S (Float32 by default; Float64 for full precision), on the staged data's backend — KernelAbstractions CPU() or a GPU. The scale is integrated out by the package's one scale quadrature, the trapezoid logsumexp over NG log-scale nodes spanning t0 ± 7.0 around each grid point's prior centre (loss_spec(::ScaleMarginal)). Returns a (P, T) per-pair error matrix at the model each grid-point's marginal selects.

prior_loss_widths is THIS FAMILY'S tuned parameter — the IG-prior centre on the loss width (prior_loss_width, NormalizedImageFrame units), not a decision threshold. Grid point t is m's family with m's prior shape alpha0, Z̃ domain m.outlier_halfwidth (the declared outlier support, POOL_FRAME_R_MAX on pool data), centred at prior_loss_widths[t]: the grid REPLACES m's own centre. return_idxs=true also returns the selected pool indices. The pair-chunk is sized so the NG-per-work-item scratch and the score block stay under mem_budget bytes.

source
grid_evaluate([S = Float32,] spec::LossSpec, staged::IGSharedData, outlier_halfwidths;
              model_dof, dg, return_idxs = false, mem_budget = 6_000_000_000)
    -> Matrix{Float64}

Track-B mixture-marginal grid evaluation, on the staged data's backend (KernelAbstractions CPU() or a GPU), the ONLY evaluation of this evidence. For the depth-Δ quadrature selector spec (built by loss_spec — Z̃ over the FIXED [0, r_max] domain), score every staged (pair, model) at every outlier half-width in outlier_halfwidths (NormalizedImageFrame units) and return the (P, T) per-pair error matrix at each grid-point's selected model (return_idxs=true also returns the selected pool indices). Three kernels per pair-chunk: marg_mix_evidence_kernel! (E over k; the NG-node trapezoid quadrature), marg_mix_profile_kernel! (the outlier-half-width profile re-argmax over k), and the shared argmax_models_kernel!. Precision S drives the evidence arithmetic — Float64 for full precision; Float32 is the fast production setting. The pair-chunk is sized so the E block + the NG-per-work-item Dscratch stay under mem_budget bytes. model_dof (the minimal sample size, whose points are the exact inliers at the front of each column) and dg (the codimension) are the problem's, and REQUIRED: a LossSpec carries neither.

Aggregation

How a loss-width family's per-residual quality is summed over a model's residuals: Exact or LogBinned. Both evaluate the SAME scalar quality; only the aggregation differs.

RansacScoringDoneRight.Exact — Type
Exact()

Every residual through the family's scalar quality — the reference. The quality is evaluated in Float64 whatever the kernel precision S of grid_evaluate.

source
RansacScoringDoneRight.LogBinned — Type
LogBinned(bins_per_decade = 200)

The fast cross-validation aggregation: residuals histogrammed on a log-spaced d² grid. The grid has bins_per_decade bins per decade, spanning 0.01·minlosswidth² to 100·maxlosswidth², and the family's quality is evaluated at the bin centres. Out-of-range and non-finite residuals score as outliers.

Native widths

Each scorer's hyperparameter lives on its own width axis: the outlier half-width for the marginal scores, the loss width for the threshold-based family. VisualGeometryCore's width_axis(scoring) names it (this package states it for its grid families); the scale multiple → native maps to_native and native_map, and the conversions outlier_halfwidth_to_loss_width / loss_width_to_outlier_halfwidth, are VisualGeometryCore's.

Scale marginals of redescending losses

RansacScoringDoneRight.WelschMarginal — Type
WelschMarginal(; alpha0=1.0, prior_loss_width, outlier_halfwidth)

Marginal-Welsch scoring spec. prior_loss_width is the IG-prior centre on the Welsch loss width (beta0 = alpha0·prior_loss_width² ⇒ 2·alpha0 pseudo-observations at pseudo-squared-width prior_loss_width²); outlier_halfwidth bounds the density normalizer Z̃ — REQUIRED, as for every scale-marginal spec. alpha0/beta0 are the same two IG hyperparameters IGPrior names. For an (alpha0, beta0) prior not tied to a centre, ScaleMarginal{WelschShape}(alpha0, beta0; outlier_halfwidth).

The evidence is the trapezoid scale quadrature of loss_spec(::ScaleMarginal).

RansacScoringDoneRight.loss_spec — Function
loss_spec(shape, prior; Δ, r_max=POOL_FRAME_R_MAX, t_lo, t_hi, NG=1537) -> LossSpec

Build a depth-Δ quadrature-marginal spec for the loss shape under IG scale prior. Z̃ is normalised over the FIXED domain [0, r_max] (the declared outlier support POOL_FRAME_R_MAX, in the pool frame's half-diagonal unit), so the outlier half-width is decoupled from the quadrature. [t_lo, t_hi] are the log-scale grid bounds (use loss_scale_bounds(sq_residuals, n)).

source
loss_spec(m::ScaleMarginal{K}; NG=_MARG_NG) -> LossSpec

The quadrature of the full-data scale marginal m: shape K at its canonical depth, m's IG prior, Z̃ over [0, m.outlier_halfwidth] and NG log-scale nodes spanning m.t0 ± _MARG_L. The nodes lie on the ABSOLUTE lattice t = i·h, h = 2·_MARG_L/(NG − 1) (the domain snapped by at most h/2), so the specs of every grid point share their nodes and grid_evaluate(::ScaleMarginal, …) sums each model's data term once for the whole grid.

RansacScoringDoneRight.loss_scale_bounds — Function
loss_scale_bounds(sq_residuals, n; pad=4.0) -> (t_lo, t_hi)

Data-driven grid bounds on t = log sq_loss_width for a redescending-loss sweep over squared residuals sq_residuals[1:n]. The scale-posterior peak for partition k lands near sq_loss_width ≈ RSS_k/(k−m), which ranges from ≈ the tightest residual scale (small k) to ≈ the all-point scale (k=n); the returned [t_lo, t_hi] brackets that range with pad decades (natural-log) of margin on each side so the trapezoid grid covers every k's peak. Supply to loss_spec(...; t_lo, t_hi).

Scale priors

The empirical-Bayes variants of the paper fit VisualGeometryCore's IGPrior from per-pair noise-variance estimates on a validation set: IG-MLE by type-II maximum likelihood, IG-Robust with α₀ = 1 and a median-anchored β₀. The fits (PriorSpec, fit_prior, ALL_PRIOR_SPECS) are VisualGeometryEval's Tuning; a fitted prior enters a scorer as StudentTUniformScoring(P, a; prior).

SIMFIT++ loss-width estimation

A step-for-step port of Edstedt's SIMFIT++ (Parskatt/simfitpp), with a pool adapter.

SIMFIT++ configuration (the reference's constructor defaults; the reference calls the loss width its threshold). alpha is the inlier coverage the loss width targets (losswidth² = ppf{χ²dg}(alpha)·σ²); `minlosswidthandmaxloss_widthbound an acceptable loss width in the residual unit of the residuals handed to the estimator (pixels in the reference);dg` is the residual codimension (the χ² degrees of freedom).

RansacScoringDoneRight.simfitpp_loss_width — Function
simfitpp_loss_width(fit, residuals_sq, n, initial_loss_width, cfg = SimFitPP();
                    num_previous_est = 0, rng = Random.default_rng())
    -> (loss_width, success::Bool)

The reference's SIMFITPP.__call__ over n correspondences. fit(loss_width, train) estimates the geometry from the correspondences indexed by train at loss_width and returns a model handle (or nothing on failure); residuals_sq(model, val) returns the squared residuals of that model on the held-out indices val (or nothing). initial_loss_width seeds the iteration and is returned unchanged when the estimate fails (success == false); with num_previous_est = p > 0 earlier estimates behind initial_loss_width, the successful estimate is filtered as exp(log(loss_width)/(p+1) + p·log(initial_loss_width)/(p+1)).

RansacScoringDoneRight.simfitpp_select — Function
simfitpp_select(residuals::AbstractMatrix, initial_loss_width, cfg = SimFitPP();
                num_previous_est = 0, rng = default_rng())
    -> (best_idx, loss_width, success)
simfitpp_select(pair::PoolPair, initial_loss_width_px, cfg = SimFitPP(); ...)

SIMFIT++ on a fixed hypothesis pool: residuals is the pool's n×M residual matrix (points × models) in the unit initial_loss_width and the bounds of cfg are expressed in. The geometry "estimator" is the MSAC-best pool hypothesis on the train split at the current loss width, scored by its validation-split residuals; the returned index is the MSAC argmax over ALL points at the final loss width.

The pair method is PIXELS in, pixels out: it runs on pixel_residuals(pair), the pool models' residuals in pixels, so initial_loss_width_px, the bounds of cfg (the reference's pixel defaults, 0.25–8 px) and the returned loss width are all pixels. To work in the pool frame's unit instead, call the matrix method on the pair's stored residual matrix with bounds in that unit (with_residual_unit).

RansacScoringDoneRight.unbiased_median_variance — Function
unbiased_median_variance(residuals_sq, sq_loss_width; dg = 1) -> σ²

The reference's UnbiasedMed: the noise VARIANCE from the squared residuals below sq_loss_width, corrected for the truncation. With med the median of the kept residuals and ratio = sq_loss_width / med, the quantile q that the truncated median corresponds to under χ²dg solves q = F(ratio · F⁻¹(q)) / 2, iterated five times from q = 1/2; the estimate is med / F⁻¹(q). For dg == 1 a ratio below 5 has no useful fixed point and the naive med / F⁻¹(1/2) is returned (the reference's `minratio). ReturnsNaN` when no residual lies below the loss width.

It returns σ², not σ — which is why the name no longer says "scale". It was unbiased_median_scale, sitting in the same package as a partition-scale verb that returned a LINEAR σ̂. Two exported *_scale names, one squared and one not, is the ambiguity VisualGeometryCore's s2 convention exists to remove.

RansacScoringDoneRight.pixel_residuals — Function
pixel_residuals(pair::PoolPair) -> Matrix{Float32}

The image-plane Sampson residuals of the pair's stored models in the PIXEL frame, num_points × num_models. Pixels are the frame the SIMFIT++ reference works in, so its pixel bounds apply to them without any scalar approximation (the pool frame scales the two images independently, cf. residual_unit_scale). One n×M scan of the light record: the correspondences come back to pixels through the stored maps (pixel_csponds), each model by composition with the pool normalization's two sides, inv(D) ∘ M ∘ S (a pool F → T₂ᵀ F T₁, a pool H → T₂⁻¹ H T₁). A model type with neither law (a bare matrix) has no sampson_distance and is a MethodError.

It never reads the pool's stored residual matrix, so it does not depend on that matrix's residual kind. The stored residuals of an essential pool are TANGENT Sampson distances (the pool generator's residual_kind = :tangent_sampson), those of an F or H pool image-plane Sampson (:sampson); this exit is image-plane Sampson for every pool, the quantity SIMFIT++'s pixel bounds are stated in. (It used to return the stored matrix itself when both maps were the identity — the image-plane quantity for an F/H pool, but the tangent one for an E pool: two routes to two quantities under one name.)

source
RansacScoringDoneRight.residual_unit_scale — Function
residual_unit_scale(pair::PoolPair) -> Float64

Pool-frame residual units per pixel for the pair: the mean isotropic scale of the two pool-frame maps (pixel → NormalizedImageFrame). A CONVENTION, not an exact conversion — the pool frame scales the two images independently and the Sampson denominator mixes both images' gradients, so no single scalar relates the two frames per point. Use it only for soft quantities (an initial loss-width guess from a pool-frame-unit grid); anything the bounds gate must run on pixel_residuals.
